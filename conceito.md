# O que é DOM?

O **DOM (Document Object Model)** é a representação do HTML em forma de **árvore de objeto**.

Isso permite que o JavaScript:

- Leia elementos de página 
- Modifique textos
- Troque imagens
- Reaja a cliques
- Crie elementos novos 

> O novo navegador transforma o HTML em objetos manipuláveis.
